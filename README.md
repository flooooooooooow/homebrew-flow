# homebrew-flow

Homebrew tap for [Flow](https://github.com/flooooooooooow/flow).

```bash
brew tap flooooooooooow/flow
brew install --HEAD flow
flow help
```

This is a **formula** (CLI toolchain), not a cask.

Formula source of truth: [`flooooooooooow/flow`](https://github.com/flooooooooooow/flow) → `packaging/homebrew/Formula/flow.rb`.
Sync from that repo with `./packaging/homebrew/sync-tap.sh`.
